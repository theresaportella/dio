Ferramentas Utilizadas (voltar)

A ferramenta utilizada é o VSCode com a extensão LifeServer.

Após criar o arquivo ".html", é possível clicar com o botão direito e selecionar a opção "Open with LifeServer" que vai permitir abrir a página no navegador para visualizar a construção.


Inspetor de Elementos (voltar)

No navegador, é possível clicar com o botão direito e selecionar a opção "Inspecionar" e explorar toda a construção do html.

Listas Ordenadas e Não Ordenadas (voltar)

Falando sobre listas ordenadas agora abrindo uma tag "ol" e incluindo itens com list items com a tag "li":

  1. Item 1
  2. Item 2
  3. Lista dentro da lista:
    1. Item....
    2. Item....

Falando sobre listas não ordenadas agora abrindo uma tag "ul" e incluindo itens com list items com a tag "li":

  • Item 1
  • Item 2
  • Lista ordenada dentro da lista não ordenada:
    1. Item....
    2. Item....
